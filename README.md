# اسکریپت رفع‌باک تتراشاپ

این اسکریپت خودکار، پروژه‌ی [tetrashop-pages](https://github.com/tetrashop/tetrashop-pages) را کلون کرده،
هدف آن را شناسایی و باگ‌های شناخته‌شده را اصلاح می‌کند.

## 🐞 باگ‌های رفع‌شده
- **کامپوننت خالی `App.jsx`** – اکنون `ServicePlatform` را رندر می‌کند.
- **رندر نادرست در `main.jsx`** – به‌روزرسانی به `createRoot`.
- **فقدان `lang="fa"` و `dir="rtl"`** – برای پشتیبانی راست‌به‌چپ اضافه شد.
- **خطای `terser` در بیلد** – با نصب خودکار `terser` رفع می‌شود.
- **فایل‌های پشتیبان اضافی** (`App.js.backup`, `App.js` قدیمی) حذف می‌شوند.
